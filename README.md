# Bioinformatics algorithms

Python exercises on sequence transformations, mutation/fitness search, alignment, CpG statistics and Markov models.

The `L*` directories contain independent examples. Install `requirements.txt` and run a selected script from its directory. Inputs are generally small sequence examples embedded in code.

Sequence alignment uses a scoring matrix and traceback. Other exercises estimate transition matrices, simulate sequences or compute window-based scores. Some `try.py` files and placeholder sections are exploratory work.

University bioinformatics coursework.
